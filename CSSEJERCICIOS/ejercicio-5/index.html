Ejercicio 5: Propiedad Display

1. Pruebas con elementos div

DIV 1: display: block
DIV 2: display: inline
DIV 3: display: inline-block
SPAN 4: display: none (oculto)

2. Pruebas con elementos span

SPAN 1: display: block SPAN 2: display: inline SPAN 3: display: inline-block SPAN 4: display: none (oculto)

Diferencias observadas

  • display: block: El elemento ocupa todo el ancho disponible de su contenedor (o respeta el width y height asignados) y fuerza un salto de línea antes y después de sí mismo.
  • display: inline: El elemento se ubica uno al lado del otro en la misma línea sin generar saltos. Su tamaño se ajusta únicamente a su contenido interno, por lo que ignora las propiedades width y height.
  • display: inline-block: Combina lo mejor de ambos: permite que los elementos se coloquen uno al lado del otro en la misma línea (como inline), pero sí respeta las dimensiones personalizadas de width, height, margin y padding vertical (como block).
  • display: none: Oculta completamente el elemento en la pantalla y elimina el espacio que ocupaba en el flujo del documento, como si no existiera visualmente.
